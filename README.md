# zashugannyy kot | Ai — веб-нейросеть

Отдельный сайт с авторизацией через одноразовый код из Telegram-бота, выбором уровней Low / Medium / High и единым веб-лимитом подписки.

## Что находится в папке

- `index.html`, `styles.css`, `script.js` — готовый интерфейс сайта.
- `config.js` — адрес нового Cloudflare Worker.
- `cloudflare/worker.js` — код, который целиком вставляется в новый Worker.
- `cloudflare/schema.sql` — таблицы для новой базы Cloudflare D1.
- `cloudflare/bot-integration-example.py` — пример выдачи кода и синхронизации подписки из Telegram-бота.
- `cloudflare/README.md` — пошаговая настройка Cloudflare.

## Веб-лимиты

| Подписка | Запросов на сайте |
|---|---:|
| Free | 3 |
| Go | 10 |
| Pro | 25 |
| Ultra | Безлимит |

Low, Medium и High используют один общий лимит. По умолчанию лимит обновляется каждый день в 00:00 по Москве. Для платных тарифов режим можно изменить на период подписки переменной `WEB_LIMIT_PERIOD`; Free при этом остаётся ежедневным.

## Быстрый запуск

1. Выполните инструкцию из `cloudflare/README.md`.
2. В `config.js` замените `https://YOUR-NEW-WORKER.workers.dev` адресом нового Worker.
3. Разместите содержимое этой папки на любом статическом хостинге.
4. Заполните веб-переменные бота по шаблону `../.env.web-ai.example`. Кнопка и команда `/web` уже добавлены в основной `bot.py`.

Ключ OpenRouter хранится только в секретах Worker и никогда не попадает в браузер.
